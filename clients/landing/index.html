What Schema does

One install. Zero configuration. Every language your codebase speaks.

Polyglot architecture graph

TypeScript, Python, Go, Java/Kotlin, Ruby, Rust, and config files. Tree-sitter extraction at IDE latency. No configuration.

Cross-language bridges

REST routes matched to handlers. gRPC proto definitions resolved to implementations. SQL queries linked to table schemas. Across languages, automatically.

Architectural rules

Write rules. Schema enforces them. Circular imports, missing middleware, contract mismatches — caught before they ship.

Structural diff

See what changed architecturally between any two Git refs. Not lines added — structural impact. Copy-ready markdown for PR descriptions.

47 MCP actions

Works with Claude Code, Cursor, Cline, Windsurf, Zed — any MCP-compatible agent. The agent sees the architecture before it writes code.

Datalog queries

Run architectural queries against your codebase. "Show me all functions that call the payment service but skip auth middleware." Bundled query library included.

Three steps

From install to full architectural visibility in under a minute.

01

Install

One command: npm i -g @schema-ai/mcp. No config files. No language servers. No project-specific setup.

02

Point

Open your codebase. Schema auto-detects languages, routes, contracts, and service boundaries. Works on polyglot monorepos.

03

See

Full architecture graph, rule evaluations, structural diffs. In your MCP agent, in Schema Studio, or via the CLI.

Built for real codebases

Not a prototype. 793 tests across 36 files. 17 namespaces. Production-grade.

CapabilityDetails
Language extractors TypeScript/JavaScript, Python, Go, Java/Kotlin, Ruby, Rust, generic config (YAML/JSON/TOML/HCL)
Cross-language bridges REST (fetch calls → route handlers), gRPC (proto services → implementations), SQL (DDL tables → ORM models). Emits implements_contract and consumes_contract edges.
Architectural rules 4 built-in rules: no-cycle, must-have-handler, must-have-inbound, must-have-outbound. Session rules and .schema/rules/ file rules. Datalog-based evaluation.
Wisdom layer 9 bundled skills (OTP supervision, CQRS, Jepsen fault classes, refactoring guides). 60-doc canon corpus with BM25 search. AGENTS.md round-trip writer.
Graph persistence SQLite-backed graph snapshots, git-SHA-tagged. SCIP import for compiler-precise cross-references.
Datalog queries graph.query action accepts Datalog. Bundled architectural search queries. Custom rules in .schema/rules/*.dl.
Plan & codemod plan.propose → plan.apply → plan.restore. Auto-rollback on failure. File snapshots. 8 bundled codemods.
Transports stdio (for MCP clients) + Streamable HTTP (for web dashboard / Studio). Same action surface on both.
