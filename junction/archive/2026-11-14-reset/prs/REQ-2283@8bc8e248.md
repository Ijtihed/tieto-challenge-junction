### What the agent did and decided
Claude Code 2.1.323 · claude-opus-5-5 · 28 turns · 38 recorded steps · run `REQ-2283-20261113-202056`

Fixed IndexOutOfRangeException in TypeCollector.GetObjectInfo when a closed generic struct from a referenced assembly is collected. The compiler loads private fields (e.g. record struct backing fields) for metadata value types; for a keyless one, the MemberNeedsKey path indexed DeclaringSyntaxReferences[0], which is empty for metadata symbols. Replaced that and the analogous BothStringAndIntKeyAreNull lookup with FirstOrDefault(), matching nearby helpers. Added a test that emits the defining library to a PE image so the consumer sees real metadata symbols; it failed with CS8785 + AD0001 before the fix and now passes, producing a GeneratedMessagePackResolver. Full SourceGenerator test suite: 168/168 passing.
